## 📊 API Endpoints (используются)

### Авторизация
- `POST /auth/register` - Регистрация
- `POST /auth/login` - Вход

### Книги
- `GET /books` - Получить список книг
- `POST /books` - Загрузить книгу
- `GET /books/{id}` - Получить книгу
- `PUT /books/{id}` - Обновить книгу
- `DELETE /books/{id}` - Удалить книгу
- `GET /books/{id}/content` - Получить presigned URL

### Полки
- `GET /shelves` - Получить список полок
- `POST /shelves` - Создать полку
- `POST /shelves/{id}/books/{book_id}` - Добавить книгу на полку
- `DELETE /shelves/{id}/books/{book_id}` - Удалить книгу с полки

### Заметки
- `GET /notes` - Получить заметки
- `POST /notes` - Создать заметку
- `PUT /notes/{id}` - Обновить заметку
- `DELETE /notes/{id}` - Удалить заметку

### Статистика и цели
- `GET /stats/reading` - Получить статистику
- `GET /goals` - Получить цели
- `POST /goals` - Создать цель
- `PUT /goals/{id}` - Обновить цель

## 🔐 Безопасность

### JWT токены
- Токены сохраняются в `localStorage`
- Автоматически добавляются в заголовок `Authorization: Bearer {token}`
- Проверяются на каждой странице
- При отсутствии токена - редирект на `/log.html`

### CORS
Настроен для:
- `http://localhost:5500` (Python HTTP server)
- `http://localhost:3000` (альтернативный порт)

### Presigned URLs
- Генерируются для скачивания книг
- Действительны 60 минут
- Не требуют авторизации после генерации
