╔══════════════════════════════════════════════════════════════════════════════╗
║                          ТЕХНОЛОГИЧЕСКИЙ СТЕК                                ║
╚══════════════════════════════════════════════════════════════════════════════╝

    Backend:
        • Python 3.11
        • FastAPI 0.104.1
        • SQLAlchemy 2.0.23 (async)
        • PostgreSQL 15
        • MinIO (S3-совместимое хранилище)
        • Docker + Docker Compose

    Frontend:
        • HTML5
        • CSS3
        • Vanilla JavaScript (ES6+)
        • Fetch API

    Безопасность:
        • JWT токены (HS256)
        • bcrypt хеширование паролей
        • CORS настроен
        • Rate limiting (10 req/min на /auth/login)
