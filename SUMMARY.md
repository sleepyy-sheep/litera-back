## 🚀 Как запустить проект

### Шаг 1: Запуск бэкенда (уже запущен!)

```cmd
# Вариант 1: Простой
start.bat

# Вариант 2: Docker Compose
cd backend
docker-compose up -d
```

### Шаг 2: Запуск фронтенда

```cmd
# Вариант 1: Python
cd frontend
python -m http.server 5500

# Вариант 2: Скрипт
cd frontend
start-frontend.bat

# Вариант 3: Live Server (VS Code)
Правой кнопкой на log.html → Open with Live Server
```

### Шаг 3: Открыть приложение

```
http://localhost:5500/log.html
```

## 🐛 Решенные проблемы

### Проблема 1: ENUM типы "already exists"
**Симптом**: API контейнер постоянно перезапускался с ошибкой "type bookformat already exists"

**Причина**: SQLAlchemy пытался создать ENUM типы при каждом запуске миграций, даже если они уже существовали

**Решение**: 
1. Добавлены ENUM типы в `docker/init-db.sql` для создания при инициализации БД
2. Убрано явное создание ENUM из миграций
3. Добавлен параметр `create_type=False` в определениях колонок

**Результат**: ✅ Миграции применяются успешно, API запускается без ошибок

### Проблема 2: Миграции не применялись
**Симптом**: База данных была пустой, таблицы не создавались

**Причина**: Конфликт ENUM типов блокировал выполнение миграций

**Решение**: После исправления проблемы с ENUM типами миграции заработали

**Результат**: ✅ Все 10 таблиц созданы успешно
