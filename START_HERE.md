# 🚀 Запуск проекта ЛитЭра

## ✅ Проект успешно настроен и готов к работе!

### Шаг 1: Запуск бэкенда (уже запущен!)

Бэкенд уже работает! Проверьте:
- ✅ API: http://localhost:8000/health
- ✅ Документация API: http://localhost:8000/docs
- ✅ MinIO консоль: http://localhost:9001 (логин: minioadmin, пароль: minioadmin123)

Если нужно перезапустить:
```cmd
cd backend
docker-compose restart
```

### Шаг 2: Запуск фронтенда

#### Вариант A: Python HTTP сервер (рекомендуется)

1. Откройте новое окно командной строки
2. Выполните:
```cmd
cd frontend
python -m http.server 5500
```

Или просто дважды кликните на `frontend/start-frontend.bat`

#### Вариант B: Live Server в VS Code

1. Откройте папку `frontend` в VS Code
2. Установите расширение "Live Server"
3. Правой кнопкой на `log.html` → "Open with Live Server"

### Шаг 3: Откройте приложение

Откройте в браузере: **http://localhost:5500/log.html**

## 📝 Первое использование

1. **Регистрация**
   - Нажмите "Зарегистрироваться"
   - Введите имя пользователя, email и пароль
   - Нажмите "Зарегистрироваться"

2. **Вход**
   - Введите email и пароль
   - Нажмите "Войти"

3. **Добавление книги**
   - На главной странице нажмите "Добавить книгу"
   - Выберите файл (поддерживаются: PDF, EPUB, FB2)
   - Выберите жанр
   - Добавьте заметки (опционально)
   - Нажмите "Добавить"

## 🔧 Управление проектом

### Остановка всех сервисов
```cmd
cd backend
docker-compose down
```

Или дважды кликните на `stop.bat`

### Просмотр логов
```cmd
cd backend
docker-compose logs -f api
```

### Перезапуск после изменений кода
```cmd
cd backend
docker-compose restart api
```

### Полная пересборка (если что-то сломалось)
```cmd
cd backend
docker-compose down -v
docker-compose up -d --build
```

## ❓ Возможные проблемы

### "Docker не запущен"
Запустите Docker Desktop и подождите, пока он полностью загрузится.

### "Порт уже занят"
Если порт 8000, 5432, 9000 или 9001 занят:
1. Остановите другое приложение, использующее этот порт
2. Или измените порты в `backend/docker-compose.yml`

### "CORS ошибка" в браузере
Убедитесь, что фронтенд запущен на порту 5500 или 3000.

### "Не могу войти после регистрации"
1. Откройте консоль браузера (F12) и проверьте ошибки
2. Проверьте логи API: `cd backend && docker-compose logs -f api`
3. Убедитесь, что используете правильный email и пароль

### API не отвечает
```cmd
cd backend
docker-compose ps
docker-compose logs api
```

Если контейнер постоянно перезапускается:
```cmd
cd backend
docker-compose down -v
docker-compose up -d --build
```
