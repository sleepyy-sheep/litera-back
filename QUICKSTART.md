# 🚀 Быстрый старт ЛитЭра

## Шаг 1: Запуск бэкенда

Дважды кликните на файл `start.bat` в корне проекта или выполните в командной строке:

```cmd
start.bat
```

Это запустит:
- ✅ PostgreSQL базу данных
- ✅ MinIO хранилище для файлов книг
- ✅ FastAPI сервер

## Шаг 2: Запуск фронтенда

### Вариант A: Python HTTP сервер (проще)

Дважды кликните на `frontend/start-frontend.bat` или выполните:

```cmd
cd frontend
start-frontend.bat
```

### Вариант B: Live Server в VS Code (удобнее для разработки)

1. Откройте папку `frontend` в VS Code
2. Установите расширение "Live Server" (если еще не установлено)
3. Правой кнопкой на `log.html` → "Open with Live Server"

## Шаг 3: Откройте приложение

Откройте в браузере: **http://localhost:5500/log.html**

### Первый вход

1. Нажмите "Зарегистрироваться"
2. Заполните форму:
   - Имя пользователя
   - Email
   - Пароль
3. После регистрации войдите с этими данными

## Проверка работы

### Бэкенд работает?

Откройте: http://localhost:8000/health

Должен вернуть:
```json
{
  "status": "ok",
  "db_connected": true
}
```

### API документация

Откройте: http://localhost:8000/docs

Здесь можно протестировать все API endpoints.

### MinIO консоль

Откройте: http://localhost:9001

- Логин: `minioadmin`
- Пароль: `minioadmin123`

## Остановка проекта

Дважды кликните на `stop.bat` или выполните:

```cmd
stop.bat
```

## Возможные проблемы

### "Docker не запущен"

Запустите Docker Desktop и подождите, пока он полностью загрузится.

### "Порт уже занят"

Если порт 8000, 5432, 9000 или 9001 занят другим приложением:

1. Остановите другое приложение
2. Или измените порты в `backend/docker-compose.yml`

### "CORS ошибка" в браузере

Убедитесь, что фронтенд запущен на порту 5500 (или 3000). Эти порты разрешены в настройках CORS бэкенда.

### "Не могу войти после регистрации"

1. Проверьте консоль браузера (F12) на наличие ошибок
2. Проверьте логи API: `cd backend && docker-compose logs -f api`
3. Убедитесь, что используете правильный email и пароль
